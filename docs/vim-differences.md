# Vim との違い

| 項目 | 内容 |
|---|---|
| 作成日 | 2026-11-16 |
| 位置づけ | Vim 9.1 との食い違いのうち、見つけたが直さないと決めたものの一覧 |
| 比べた Vim | Vim 9.1 を Ex モードでない起動（`vim -Nu NONE -i NONE -n --not-a-term`）で動かし、`feedkeys(keys, "xt")` で入力した結果 |

要件定義 1 章は、Vim との 100% の互換を目指さないとしている。
このため、Vim との細かい食い違いは、日常の編集で困るもの（バッファの内容が変わるもの、よく打つ操作で起きるもの）だけを直し、残りをここに書く（#89）。

個々の関数の振る舞いの違い（要件が Vim と違う挙動を定めているもの。FR-09 の正規表現の文法など）は、その関数の doc コメントに書く（`internal/command` のパッケージの doc コメント）。
この一覧には、doc コメントの 1 か所に収まらない違いと、未実装の機能だけを書く。

## 一覧

| 違い | 例（`\|` はカーソル） | Vim 9.1 | この実装 | 直さない理由 | 直すのに要るもの |
|---|---|---|---|---|---|
| `\|` でつないだ Ex コマンドのアンドゥの後のカーソル | `\|xyz`、`  abc`、`  dbf`、`  ghi`、`  jkl` で `:4d\|2d<CR>u` | 1:2 | 3:2 | バッファの内容は Vim と同じで、カーソルの位置だけが違う。`\|` で上の行を後から変える使い方は少ない | `internal/buffer` のアンドゥの単位が、編集の行の塊（Vim の entry）ごとにカーソルを決められること |
| 同じ例の `:4d\|2d<CR>u<C-r>` | 同上 | 2:2 | 1:2 | 同上 | 同上 |
| 同じ例の `:4s/h/H/\|2d<CR>u` | 同上 | 1:2 | 3:0 | 同上 | 同上 |
| 何も変えないオペレーター（行頭の `dh`、空の行の `dl`）が空のアンドゥの単位を作らない | `\|abc` で `xdhu` | `bc`（`u` は `dh` の空の単位を取り消す） | `abc`（`u` は `x` を取り消す） | 何も消さない操作の直後に `u` を打つ場面は少ない | `internal/buffer` が、編集を含まないアンドゥの単位を記録できること |
| 同上 | 空の行と `\|abc` の 2 行で `xkdlu` | 1 行目が空、2 行目が `bc`、カーソルは 0:0 | 1 行目が空、2 行目が `abc`、カーソルは 1:0 | 同上 | 同上 |
| Ex の `:normal` が無い（`:g/…/normal` を含む） | `:normal x` | カーソルの文字を消す | E492 で失敗する | 標準の Ex コマンドの対象の一覧（#9 の案）に無い | Ex コマンドの表への追加と、`internal/command` のキーの解釈を Ex から呼ぶ口 |

カーソルの位置は「行:バイト」で、どちらも 0 から数える。

## 直したもの

#89 で直したものを、比べるときのために残す。

- ビジュアルモードのカーソルは、j、k、`$` で移った短い行や、`l` で最後の文字から進んだ行では、Vim と同じく行末の後（NUL の位置）に置く。文字単位の選択の始まりがここにあれば、その行の改行から選び（`a` と `bcd|e` の `vkd` は `a` を残す）、終わりがここにあれば、その行の改行まで選ぶ（`ab|c` と `d` と `e` の `vjd` は `abe` になる）。ここから `h` で戻る列も Vim と同じになる（`ab` と `cdef|g` の `vkhCX<Esc>u` のカーソルは 1:1）。表は `internal/command/visual_eol_test.go` にある
